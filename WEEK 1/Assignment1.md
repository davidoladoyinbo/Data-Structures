1. What is a Stack?
A stack is a type of data structure used to store information. It works using the LIFO (Last In, First Out) method.

This means that the last item you put inside the stack will be the first item to come out.

Example: Imagine putting books on top of each other. If you want to remove a book, you will remove the one on top first.
2. Real-Life Applications of Stack
These are some places where stacks are used in real life:
1. Browser History: When using Google Chrome, we can go back to the previous page we visited.
2. Undo Operation: When typing in Microsoft Word, we can undo the last thing we typed.
3. Redo Operation: We can bring back something we previously removed.
4. Calculator: Stacks help calculators solve mathematical calculations.
5. Text Editors: They help check if brackets are properly arranged when writing code.
6. Computer Programming: Stacks help computers remember which function is currently running.
7. Mobile Applications: Some apps use stacks to help users return to previous screens.
8. Games: Stacks can be used in games to remember previous moves.
