1. Introduction
A queue is a data structure that works with the FIFO (First In, First Out) rule. This means that the first person or item that enters the queue will be the first to leave.

Examples of Queue in Real Life:
1. People waiting in a bank.
2. Cars waiting at a traffic light.
3. Students waiting to buy food.
4. Documents waiting to be printed.
5. Customers waiting for their turn.
2. Operations of Queue
1. Enqueue: Used to add an item to the queue.
2. Dequeue: Used to remove an item from the queue.
3. Peek: Used to see the first item.
4. Rear: Used to see the last item.
5. isEmpty: Checks if the queue is empty.
6. isFull: Checks if the queue is full.
7. Display: Shows all the items in the queue.
8. Size: Counts the number of items in the queue.
